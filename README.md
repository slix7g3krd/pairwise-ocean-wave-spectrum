# pairwise-ocean-wave-spectrum

海面在远处反复出现同一块浪，FFT 周期与网格 tile 尺寸不匹配，平铺接缝一眼可见；风谱只取单一方向，浪峰排成整齐的平行线；choppiness 系数写死，风暴天气下浪尖互相穿插；法线由高度图差分得到但没按网格缩放，远处高光碎成噪点；多级谱拼接时高频层相位没对齐，级联边界出现十字接缝；时间累积用绝对时间，长时间运行后相位精度丢失；深度吸收按固定颜色乘，浅水区也发黑；泡沫阈值只看高度，浪尖背面也长白沫；LOD 网格在远处直接降采样高度，浪形被抹平；性能档减少谱层数却没重新归一化能量，海面变暗。render/ocean_fft.py 是核心，tests/test_ocean_fft.py 15个红。要修的是：FFT 周期对齐 tile；风谱按方向分布积分；choppiness 按风速钳制；法线按网格尺度重算；级联谱相位对齐；时间相位取模；吸收按深度积分；泡沫按朝向与高度联合；远网格保留谱能量；降档重算归一化。

## 运行

```bash
python -m pytest tests -q
```
